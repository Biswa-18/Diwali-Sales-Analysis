🪔 Diwali Sales Analysis
📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Diwali sales data using Python. The goal is to understand customer purchasing behavior, analyze sales patterns, and identify trends that can help businesses make better decisions during the festive season.

🎯 Objectives
Analyze customer purchasing behavior during Diwali.
Explore sales patterns across different demographic groups.
Understand purchasing trends by gender, age group, state, occupation, and product category.
Identify patterns that can support business and marketing decisions.
🛠️ Technologies Used
Python — Data analysis and manipulation
Pandas — Data cleaning and data manipulation
NumPy — Numerical operations
Matplotlib — Data visualization
Seaborn — Statistical visualization
Jupyter Notebook — Interactive analysis
📂 Project Files
Diwali_Sales_Analysis.ipynb — Jupyter Notebook containing the analysis, visualizations, and code.
Diwali Sales Data.csv — Dataset used for the analysis.
🔍 Analysis Performed
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Customer distribution by gender and age group
Sales analysis by gender
Analysis of purchasing trends across states and occupations
Product category and order analysis
Data visualization using Matplotlib and Seaborn
📊 Key Questions Explored
Which gender contributes more to total sales?
Which age groups show different purchasing patterns?
How do sales vary across states?
Which occupations are represented among customers?
Which product categories attract customer purchases?
⚙️ How to Run the Project
Clone or download this repository.
Install Python and Jupyter Notebook.
Install the required libraries:
   pip install pandas numpy matplotlib seaborn jupyter

Open the notebook:
   jupyter notebook

Open Diwali_Sales_Analysis.ipynb and run the cells.

Make sure the CSV dataset is available in the same directory as the notebook.

💡 Conclusion

This project demonstrates the use of Python libraries for data cleaning, exploratory data analysis, and visualization. It explores customer demographics and sales patterns to develop a better understanding of purchasing behavior during the Diwali festival.
